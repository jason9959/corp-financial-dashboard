# 기업 재무 대시보드

한국 DART와 미국 SEC EDGAR의 공식 공시 데이터를 조회하는 Streamlit 재무 대시보드입니다.
기존 포트폴리오 화면의 1180px 중앙 정렬, 흰 배경, 파란 강조색, 카드 구성을 참고했습니다.

운영 화면: https://cinema99594.streamlit.app/

## 실행

Python 3.11 이상을 권장합니다.

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

기업명 또는 종목코드를 검색하고 분기/연도, 시작/종료 기간을 지정해 조회합니다.

실제 API 연결 시 `.streamlit/secrets.toml.example`을 `.streamlit/secrets.toml`로 복사한 뒤
`DART_API_KEY`와 `SEC_USER_AGENT`를 입력합니다. 실제 인증정보가 든 파일은 Git에서 제외됩니다.

## 확정한 화면 범위

- 국가 메뉴 대신 기업 검색 결과로 국가와 데이터 공급자를 결정
- 연도별/분기별 및 시작/종료 기간 입력
- 1. 자산, 부채, 자본
- 2. 매출액, 영업이익, 당기순이익
- 3. 영업/투자/재무 현금흐름, 현금 증가(감소), 기초/기말 현금 및 현금성자산
- 각 그룹을 기간별 묶은 막대그래프로 비교하고 상세 수치 제공
- CAPEX와 비율·파생 지표는 기본 레이아웃 검토 후 추가

## 실제 데이터 연결 단계

1. DART/SEC 기업 마스터와 별칭으로 검색하고 복수 후보는 사용자가 선택한다. 입력 언어로 국적을 추정하지 않는다.
2. 한국은 연결재무제표 우선, 별도 전환 시 표시한다. 미국은 회계연도와 실제 보고기간을 보존한다.
3. 재무상태는 기말 잔액, 손익과 현금흐름은 기간값이다. 누적 공시에서 분기 단독값을 구할 때 비교 가능한 기간만 차감하고 계산값으로 표시한다.
4. 분기 기초 현금은 분기 시작 잔액을 사용한다. 연초 잔액을 모든 분기에 반복하지 않는다.
5. 현금 범위(제한된 현금 포함 여부), 환율 효과, 정정공시, 누락값, 출처 계정과목을 보존한다. 누락값은 0으로 대체하지 않는다.
6. 원문 공시 링크, 보고기간, 통화/단위 및 조회 시점을 표시한다.

GitHub 배포 진입점은 `app.py`입니다. DART 인증키는 GitHub에 올리지 않고 배포 환경의 secrets로 관리합니다.
현재 공개 앱은 Streamlit Community Cloud에 배포되어 있으며, 로컬 변경은 검토 후 GitHub에 반영합니다.

API 연결 원칙과 필요한 설정은 [API_INTEGRATION_PLAN.md](API_INTEGRATION_PLAN.md)를 참고하세요.
